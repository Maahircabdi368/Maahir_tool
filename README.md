# Maahir_tool

**Maahir_tool** waa tool fudud oo kuu oggolaanaya inaad sameyso baaritaanno IP ah oo kala duwan. Waxaa ku jira:

### Features:
1. **IP Scanner** – Baadhitaanka ports-ka muhiimka ah ee IP-ga.
2. **IP Tracker** – Helitaanka macluumaad IP sida wadanka, gobolka, ISP, iwm.
3. **WHOIS Info** – Ka hel macluumaadka domain-ka sida registrar, taariikhda la diiwaangeliyay, DNS, iwm.
